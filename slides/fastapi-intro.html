パスパラメータ：URL の「途中」を変数に 
@app.get("/hello/{name}")
def hello_name(name: str):
    return {"message": f"こんにちは、{name}さん"}

{name} に入った文字が、引数 name に入る。

クエリパラメータ：URL の「? 以降」を変数に 
@app.get("/add")
def add(a: int, b: int):
    return {"result": a + b}

URL に書いていない引数は ?a=1&b=2 から受け取る。

URL は「何を」（名詞）、メソッドは「どうする」（動詞）。　この4つで、作る・読む・更新・削除（CRUD）が全部できる。

SQL の4つの命令は、HTTP メソッドと対応する

HTTPSQL意味SQL の例
GETSELECT取り出すSELECT * FROM todos
POSTINSERT追加するINSERT INTO todos (title, done) VALUES (?, ?)
PUTUPDATE書き換えるUPDATE todos SET title = ?, done = ? WHERE id = ?
DELETEDELETE削除するDELETE FROM todos WHERE id = ?

* は「全部の列」、WHERE id = ? は「id が〇〇の行だけ」という条件。WHERE を忘れると全行が対象になるので注意。

? はプレースホルダ（値の差し込み口）

値は ? の位置に、あとからタプルで渡す。execute(sql, (title, done))

文字列をつなげて SQL を作らない

f"... WHERE id = {todo_id}" は SQL インジェクション（乗っ取り）の原因。必ず ? を使う。
