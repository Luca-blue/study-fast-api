@app.post("/todos", status_code=201)1
def create_todo(todo: TodoIn):
    new_id = max(todos, default=0) + 1
    todos[new_id] = {"id": new_id, **todo.model_dump()}2
    return todos[new_id]

@app.put("/todos/{todo_id}")
def update_todo(todo_id: int, todo: TodoIn):3
    if todo_id not in todos:
        raise HTTPException(status_code=404, detail="Todo not found")
    todos[todo_id] = {"id": todo_id, **todo.model_dump()}
    return todos[todo_id]

@app.delete("/todos/{todo_id}")
def delete_todo(todo_id: int):
    if todo_id not in todos:
        raise HTTPException(status_code=404, detail="Todo not found")
    del todos[todo_id]
    return {"ok": True}

CH.07DB

SQL の4つの命令は、HTTP メソッドと対応する

HTTPSQL意味SQL の例
visibilityGETSELECT取り出すSELECT * FROM todos
addPOSTINSERT追加するINSERT INTO todos (title, done) VALUES (?, ?)
editPUTUPDATE書き換えるUPDATE todos SET title = ?, done = ? WHERE id = ?
deleteDELETEDELETE削除するDELETE FROM todos WHERE id = ?

* は「全部の列」、WHERE id = ? は「id が〇〇の行だけ」という条件。WHERE を忘れると全行が対象になるので注意。

input ? はプレースホルダ（値の差し込み口）

値は ? の位置に、あとからタプルで渡す。execute(sql, (title, done))

warning 文字列をつなげて SQL を作らない

f"... WHERE id = {todo_id}" は SQL インジェクション（乗っ取り）の原因。必ず ? を使う。
